# Je débute la guitare électrique – Joue avec Bernard

Version en ligne de la méthode de guitare électrique pour débutants de Mickael Le Van, avec Bernard le raton laveur.

Les 57 morceaux de la méthode sont jouables directement dans le navigateur :

- la partition d'origine, avec la note jouée surlignée ;
- un accompagnement de batterie (rock, valse, 6/8 ou swing selon le morceau), précédé d'un décompte ;
- la mélodie en playback, que l'on peut couper pour jouer seul ;
- un schéma du manche qui montre où poser les doigts (masquable, avec une option gaucher) ;
- trois tempos (lent, moyen, rapide) et un réglage fin ;
- la lecture en boucle, ou à partir de n'importe quelle mesure (toucher une note) ;
- des consignes expliquées simplement avant chaque morceau et un récapitulatif à la fin de chaque chapitre.

Tout tient dans le fichier `index.html`. Aucune donnée n'est envoyée : seuls les réglages et les morceaux déjà joués sont mémorisés dans le navigateur.
